# SaaS and IT

## What matters
Time to first value, adoption, and expansion — not the initial contract. A signed deal with
no activation is churn on a delay.

## Discovery questions
- What are you using now, and what made you start looking?
- Who uses it daily, and how many of them?
- What does the current process cost in hours per week?
- What has to be true 90 days from now for this to be judged a success?
- Who owns the budget, and does this need security or legal review?

## Stakeholder map
Champion (feels the pain), economic buyer (signs), technical evaluator (can veto),
end users (can quietly kill adoption), security/procurement (can delay for months).
Never run an enterprise deal with only a champion.

## Objections
- "Уже используем X" → focus on the specific gap, propose a parallel pilot on one team.
- "Нужна интеграция с Y" → confirm feasibility precisely; vague promises here destroy deals later.
- "Дорого" → reframe from license cost to cost per user per month against hours saved.
- "Безопасность" → have documentation ready before it's asked for; this delay is avoidable.

## KPI
MRR/ARR, activation rate, time to first value, seat expansion, NRR, logo churn,
trial-to-paid, pilot-to-rollout, CAC payback months.
