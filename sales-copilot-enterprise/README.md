# Sales Copilot Enterprise — v1.0

Custom Claude Skill для коммерческой работы: разбор сделок и переписки, квалификация, скрипты,
возражения, переговоры, КП, коучинг, прогноз.

## Логика

Два слоя. `SKILL.md` решает, **что за ситуация** и **какой файл открыть**; `references/` содержит
знание. Claude подгружает один-два файла под задачу, а не всё сразу — поэтому объём знаний можно
наращивать без потери качества ответов.

Первое решение в каждом ответе — режим: enterprise (несколько ЛПР, месяцы, закупки) или
SMB/полевые продажи (решает владелец, дни, небольшой чек). Советы у них противоположные, и
смешение этих двух логик — основная причина, по которой «универсальные» продажные промпты дают
бесполезные ответы.

## Использование

- **Как skill** — сохранить `.skill`, работает во всех чатах автоматически.
- **Как проект для команды** — см. `PROJECT-SETUP.md`.

## Что осознанно не делалось

Перечисление 50+ методологий и 500+ возражений списком. Названия фреймворков модель знает и так;
ценность в том, **когда** и **почему** их применять. Восемь проработанных возражений с логикой
«что стоит за словами» дают больше, чем пятьсот строк каталога.
