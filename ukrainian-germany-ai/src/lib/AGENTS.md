- Reply letters are assembled by the pure `src/lib/letter-compose.ts` (DIN 5008 header, Berlin date, Betreff, closing) from analysis fields; AI only produces the body via `translateReply` from the user's own words — so header fixes never rewrite the body and the AI cannot invent promises. `letters.reply_de` stores the fully composed letter. `buildMailto` puts the letter text into the email body and never claims an attachment.
- Saved-letter organisation grouping and deadline urgency use the pure `letter-list` helpers and Berlin calendar dates — presentation stays testable without changing stored letters or AI analysis.
- Short analysis fields are optional in saved data and required-but-nullable in the AI wire schema; normalize their length before saving and gate the summary with `getLetterShortSummary` — preserves strict output and older-letter compatibility.
- Letter analysis and reply translation proofread generated prose within the existing AI request using language-specific instructions and examples; original facts and verbatim quotes remain untouched — avoids mixed-language output without extra calls or rewriting saved evidence.
- Analysis risk/type/deadline-evidence fields are optional in saved data; `verifyDeadlineQuote` drops a deadline whose quote is absent from the source text (and marks it low-confidence when the quote does not contain the date, see `quoteContainsDate`); `getLetterInsights` supplies defaults — keeps deadlines evidence-backed and older letters readable.
- Letter ratings go through authenticated `submitFeedback` (src/lib/feedback.functions.ts) with zod validation and an ownership check; one row per user+letter, no letter text, no AI/quota — keeps feedback cheap and private.
- Organisation type hints in parentheses come only from the pure `describeAuthority` (src/lib/authority.ts) at display time; stored data and exported PDF/DOCX letters keep the raw name — so official letters stay clean.
- Daily source sections independently search and extract BAMF and Germany4Ukraine through the linked Parallel connection, storing localized results in daily_content payloads; source URLs are allowlisted and unchanged, unavailable sources cannot block the other, and undated guidance is never labelled a new law.
- Grouped home FAQs live in `letter-faq.ts` in all UI languages and read quota constants — explanations match available features without duplicating limits.
- AI calls share `ai-gateway.server.ts` (model, provider options, error codes); never create another provider instance.
- `persistAnalysis` and the editors surface save errors (`SAVE_FAILED`) instead of failing silently.
